## 2. ② halfvec 전환 (마이그 036)

- 실측 전제: pgvector 0.8.0, `vector(1024)` 컬럼 2개(`chunks.dense_vec`, `documents.doc_embedding` 14행 — 후자는 그대로), `dense_vec` 참조 함수는 2개뿐.
- 설계: `ALTER COLUMN ... TYPE halfvec(1024)`(테이블 재작성) → `hnsw (dense_vec halfvec_cosine_ops)` → 함수 2개는 비교식만 `query_dense::halfvec(1024)`. 파라미터 타입은 `vector` 그대로라 **Edge 호출 코드 변경 0**. 쓰기 쪽(supabase-js 배열)은 텍스트 입력이라 그대로.
- **`supabase db query --linked` 는 statement_timeout 120s** (실측 `pg_sleep(150)` → 57014 취소, 2:03 만에). 테이블 재작성이 얼마나 걸릴지 몰라 **pg_cron 일회성 잡**으로 돌렸다: `SET statement_timeout=0` + `DO` 블록(`LOCK TABLE` 선점 → 타입이 아직 `vector` 면 실행) + 함수 재정의 + 자기 unschedule. 겹침 방지는 LOCK 뒤 카탈로그 재확인.
- 실행: 01:46:00 시작 → 01:46:37 성공. **37초.**
