# Phase 1 — Deno 기반 계층 구현 플랜

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development 또는 superpowers:executing-plans 로 task 단위 실행. 체크박스(`- [ ]`) 로 진행 추적.
> **선행 조건:** `2026-08-24-railway-제거-supabase-전면이관.md` 의 Phase 0 스파이크 PASS.

**Goal:** Supabase Edge Functions 위에 Jet-Rag 백엔드의 공통 기반(`_shared/`)을 세우고, `/auth/me` 가 **기존 프론트 토큰 그대로** 200 을 반환하는 것을 증명한다.

**Architecture:** `supabase/functions/_shared/` 에 상태 없는 공통 모듈을 만든다. 현행 Python 의 `@lru_cache` 싱글톤은 상주 프로세스 전제이므로 전부 제거하고, 요청 스코프 생성 또는 모듈 스코프 상수로 대체한다. 공개 URL·쿠키 도메인은 **Cloudflare Worker 리버스 프록시**로 보존해 프론트 코드 변경을 0 으로 만든다.

**Tech Stack:** Deno / TypeScript / `jose`(JWT·JWKS) / `@supabase/supabase-js` / Cloudflare Workers / `deno test`

## 0. Phase 1 이 반드시 풀어야 하는 제약

### 제약 1 — 쿠키 도메인 (프론트 인증이 통째로 끊기는 문제)

`web/src/lib/api/client.ts:55` 는 브라우저에서 `credentials: 'include'` 로 호출하고, 백엔드는 `sb-<ref>-auth-token` httpOnly 쿠키에서 토큰을 꺼낸다(`app/auth/cookie_token.py`). 이 쿠키는 `web/src/lib/supabase/server.ts:43` 의 `COOKIE_DOMAIN` 으로 `.woong-s.com` 에 스코프돼 있다.

**API 를 `<ref>.supabase.co` 로 옮기면 브라우저가 이 쿠키를 보내지 않는다 — 로그인 사용자 전원의 브라우저 직접 호출이 익명으로 강등된다.**

### 제약 2 — 경로 구조

Edge Functions 의 URL 은 `/functions/v1/<function-name>` 으로 고정이다. 현행 프론트는 `${BASE_URL}/search`, `${BASE_URL}/documents/...` 를 호출한다(`client.ts:1`, `index.ts:122`, `share/route.ts:27`).

### 채택 해법 — Cloudflare Worker 리버스 프록시

```
브라우저 ──(쿠키 .woong-s.com 자동 첨부)──▶ jetrag-api.woong-s.com   [Cloudflare Worker]
                                                    │  경로 매핑
                                                    ▼
                                        <ref>.supabase.co/functions/v1/api-*
```

| 대안 | 쿠키 유지 | 프론트 변경 | 추가 비용 |
|---|---|---|---|
| **Cloudflare Worker 프록시 (채택)** | O | **0줄** | 0 (기존 벤더) |
| Supabase Custom Domain 애드온 | O | 3개 파일 경로 수정 | 유료 애드온 |
| `*.supabase.co` 직접 호출 | **X — 인증 붕괴** | 다수 | 0 |

프록시는 Phase 6 의 **점진적 트래픽 전환 지점**이기도 하다 — 경로별로 신/구 백엔드를 나눠 보낼 수 있어 한 번에 전부 넘기지 않아도 된다.

/**
 * app/config.py 포팅. Python 의 @lru_cache 싱글톤은 상주 프로세스 전제이므로 제거하고,
 * 요청마다 loadSettings() 를 호출한다 (ENV 읽기는 비용이 무시 가능).
 * 테스트 주입을 위해 getEnv 를 인자로 받는다 — Deno.env 직접 의존 금지.

export type EnvReader = (key: string) => string | undefined;

export interface Settings {
  supabaseUrl: string;
  supabaseServiceRoleKey: string;
  supabaseStorageBucket: string;
  geminiApiKey: string;
  hfApiToken: string;
  defaultUserId: string;
  ownerUserId: string | null;
  authEnabled: boolean;
  supabaseJwtSecret: string | null;
  supabaseJwtAlgorithm: string;
  supabaseJwksUrl: string | null;
  staleIngestJobHours: number;
  chunkUpsertBatchSize: number;
  quotaEnforcementEnabled: boolean;
  corsOrigins: string[];
}

const STALE_HOURS_DEFAULT = 24;
const STALE_HOURS_MIN = 1;
const STALE_HOURS_MAX = 168;
const DEFAULT_CORS = "http://localhost:3001,http://localhost:3000";

function required(read: EnvReader, key: string): string {
  const v = read(key);
  if (!v) throw new Error(`${key} 가 설정되지 않았습니다 (Edge Function secrets 확인).`);
  return v;
}

function bool(read: EnvReader, key: string, fallback: boolean): boolean {
  const v = read(key);
  if (v === undefined) return fallback;
  return ["true", "1", "yes"].includes(v.trim().toLowerCase());
}

function int(read: EnvReader, key: string, fallback: number, min: number, max: number): number {
  const raw = read(key);
  if (raw === undefined) return fallback;
  const n = Number.parseInt(raw, 10);
  if (Number.isNaN(n)) return fallback;
  return Math.min(max, Math.max(min, n));
}

export function loadSettings(read: EnvReader = (k) => Deno.env.get(k)): Settings {
  return {
    supabaseUrl: required(read, "SUPABASE_URL"),
    supabaseServiceRoleKey: required(read, "SUPABASE_SERVICE_ROLE_KEY"),
    supabaseStorageBucket: read("SUPABASE_STORAGE_BUCKET") ?? "documents",
    geminiApiKey: read("GEMINI_API_KEY") ?? "",
    hfApiToken: read("HF_API_TOKEN") ?? "",
    defaultUserId: read("JETRAG_DEFAULT_USER_ID") ?? "00000000-0000-0000-0000-000000000001",
    ownerUserId: read("OWNER_USER_ID") ?? null,
    authEnabled: bool(read, "JETRAG_AUTH_ENABLED", false),
    supabaseJwtSecret: read("SUPABASE_JWT_SECRET") ?? null,
    supabaseJwtAlgorithm: read("SUPABASE_JWT_ALGORITHM") ?? "HS256",
    supabaseJwksUrl: read("SUPABASE_JWKS_URL") ?? null,
    staleIngestJobHours: int(read, "JETRAG_STALE_INGEST_JOB_HOURS",
      STALE_HOURS_DEFAULT, STALE_HOURS_MIN, STALE_HOURS_MAX),
    chunkUpsertBatchSize: int(read, "JETRAG_CHUNK_UPSERT_BATCH_SIZE", 50, 1, 10_000),
    quotaEnforcementEnabled: bool(read, "JETRAG_QUOTA_ENFORCEMENT_ENABLED", true),
    corsOrigins: (read("JETRAG_CORS_ORIGINS") ?? DEFAULT_CORS)
      .split(",").map((s) => s.trim()).filter(Boolean),
  };
}

/** app/auth/cookie_token.py 포팅. 모든 실패는 null (graceful) — 호출부가 401 변환. */
const NAME_PREFIX = "sb-";
const NAME_SUFFIX = "-auth-token";
const BASE64_PREFIX = "base64-";
const MAX_CHUNKS = 16;

export function deriveProjectRef(supabaseUrl: string): string | null {
  if (!supabaseUrl) return null;
  let host: string;
  try {
    host = new URL(supabaseUrl).hostname;
  } catch {
    return null;
  }
  if (!host) return null;
  const ref = host.split(".", 1)[0];
  return ref || null;
}

function joinChunked(cookies: Record<string, string>, base: string): string | null {
  const single = cookies[base];
  if (single !== undefined) return single;
  const parts: string[] = [];
  for (let i = 0; i < MAX_CHUNKS; i++) {
    const chunk = cookies[`${base}.${i}`];
    if (chunk === undefined) break;   // gap 에서 중단 — Python 구현과 동일
    parts.push(chunk);
  }
  return parts.length ? parts.join("") : null;
}

function decodeValue(raw: string): unknown | null {
  let payload = raw;
  if (payload.startsWith(BASE64_PREFIX)) {
    const enc = payload.slice(BASE64_PREFIX.length);
    try {
      const padded = enc.replace(/-/g, "+").replace(/_/g, "/") +
        "=".repeat((4 - (enc.length % 4)) % 4);
      payload = new TextDecoder().decode(
        Uint8Array.from(atob(padded), (c) => c.charCodeAt(0)),
      );
    } catch {
      return null;
    }
  }
  try {
    return JSON.parse(payload);
  } catch {
    return null;
  }
}

export function extractAccessToken(
  cookies: Record<string, string>,
  projectRef: string,
): string | null {
  if (!projectRef) return null;
  const raw = joinChunked(cookies, `${NAME_PREFIX}${projectRef}${NAME_SUFFIX}`);
  if (raw === null) return null;
  const decoded = decodeValue(raw);
  if (decoded && typeof decoded === "object" && !Array.isArray(decoded)) {
    const t = (decoded as Record<string, unknown>).access_token;
    return typeof t === "string" && t ? t : null;
  }
  if (Array.isArray(decoded) && decoded.length) {
    const first = decoded[0];
    return typeof first === "string" && first ? first : null;
  }
  return null;
}

/** Request 의 Cookie 헤더를 dict 로 파싱 (FastAPI 의 request.cookies 대응). */
export function parseCookieHeader(header: string | null): Record<string, string> {
  if (!header) return {};
  const out: Record<string, string> = {};
  for (const part of header.split(";")) {
    const idx = part.indexOf("=");
    if (idx <= 0) continue;
    out[part.slice(0, idx).trim()] = decodeURIComponent(part.slice(idx + 1).trim());
  }
  return out;
}

/**
 * app/auth/jwt_verify.py 포팅 (PyJWT → jose).
 * 대칭(HS*) 은 shared secret, 비대칭(ES*/RS*) 은 JWKS 공개키로 검증한다.
 * 이 프로젝트의 Supabase 는 ECC(P-256) 이므로 ES256+JWKS 가 주 경로.
 */
import * as jose from "npm:jose@5";
import type { Settings } from "./config.ts";

const AUDIENCE = "authenticated";
const SYMMETRIC = new Set(["HS256", "HS384", "HS512"]);
const ASYMMETRIC = new Set(["ES256", "ES384", "ES512", "RS256", "RS384", "RS512"]);

export class JWTValidationError extends Error {
  constructor(message: string) {
    super(message);
    this.name = "JWTValidationError";
  }
}

export interface VerifiedToken {
  userId: string;
  email: string | null;
}

/**
 * JWKS 원격 키셋 캐시. jose 의 createRemoteJWKSet 이 자체 캐시 + kid 미스 시 재조회를
 * 수행하므로, 모듈 스코프에 URL 별로 보관한다. Edge Function 인스턴스가 재사용되는 동안
 * 유지되고, 콜드스타트마다 다시 만들어진다 (PyJWKClient 싱글톤과 동일한 수명 특성).
 */
const jwksCache = new Map<string, ReturnType<typeof jose.createRemoteJWKSet>>();

function getJwks(url: string) {
  let s = jwksCache.get(url);
  if (!s) {
    s = jose.createRemoteJWKSet(new URL(url));
    jwksCache.set(url, s);
  }
  return s;
}

export async function verifyJwt(token: string, settings: Settings): Promise<VerifiedToken> {
  if (!token) throw new JWTValidationError("토큰이 비어 있습니다.");

  const alg = settings.supabaseJwtAlgorithm;
  let key: Parameters<typeof jose.jwtVerify>[1];

  if (SYMMETRIC.has(alg)) {
    if (!settings.supabaseJwtSecret) {
      throw new JWTValidationError("JWT secret 이 설정되지 않았습니다 (서버 설정 오류).");
    }
    key = new TextEncoder().encode(settings.supabaseJwtSecret);
  } else if (ASYMMETRIC.has(alg)) {
    if (!settings.supabaseJwksUrl) {
      throw new JWTValidationError("JWKS URL 이 설정되지 않았습니다 (비대칭 JWT 검증 불가).");
    }
    key = getJwks(settings.supabaseJwksUrl);
  } else {
    throw new JWTValidationError(`JWT 알고리즘 '${alg}' 은 지원되지 않습니다.`);
  }

  let payload: jose.JWTPayload;
  try {
    ({ payload } = await jose.jwtVerify(token, key, {
      algorithms: [alg],
      audience: AUDIENCE,
      requiredClaims: ["exp", "sub"],
    }));
  } catch (e) {
    if (e instanceof jose.errors.JWTExpired) {
      throw new JWTValidationError("토큰이 만료되었습니다.");
    }
    if (e instanceof jose.errors.JWTClaimValidationFailed && e.claim === "aud") {
      throw new JWTValidationError("토큰 audience 가 유효하지 않습니다.");
    }
    if (e instanceof jose.errors.JWKSNoMatchingKey || e instanceof jose.errors.JWKSTimeout) {
      throw new JWTValidationError("JWKS 공개키 조회에 실패했습니다.");
    }
    throw new JWTValidationError("토큰 검증에 실패했습니다.");
  }

  const sub = payload.sub;
  if (!sub || typeof sub !== "string") {
    throw new JWTValidationError("토큰에 사용자 식별자(sub)가 없습니다.");
  }
  const email = typeof payload.email === "string" ? payload.email : null;
  return { userId: sub, email };
}

/**
 * app/auth/dependencies.py 포팅. FastAPI Depends 가 없으므로 핸들러가 명시 호출한다.
 * 3-way 분기(로컬 dev / 익명 데모 / 로그인)와 게이트의 의미를 그대로 보존.
 */
import type { Settings } from "./config.ts";
import { deriveProjectRef, extractAccessToken, parseCookieHeader } from "./cookie_token.ts";
import { JWTValidationError, verifyJwt } from "./jwt.ts";
import { HttpError } from "./errors.ts";

const BEARER = "Bearer ";

export interface CurrentUser {
  userId: string;
  email: string | null;
  isAuthenticated: boolean;
}

function bearerToken(req: Request): string | null {
  const h = req.headers.get("Authorization");
  if (!h || !h.startsWith(BEARER)) return null;
  return h.slice(BEARER.length).trim() || null;
}

function cookieToken(req: Request, settings: Settings): string | null {
  const ref = deriveProjectRef(settings.supabaseUrl);
  if (!ref) return null;
  return extractAccessToken(parseCookieHeader(req.headers.get("Cookie")), ref);
}

export async function getCurrentUser(req: Request, settings: Settings): Promise<CurrentUser> {
  if (!settings.authEnabled) {
    return { userId: settings.defaultUserId, email: null, isAuthenticated: true };
  }

  const token = bearerToken(req) ?? cookieToken(req, settings);
  if (token === null) {
    // 익명 데모 방문자 — owner 문서 read-only. 쓰기는 requireAuthenticatedUser 가 차단.
    return {
      userId: settings.ownerUserId ?? settings.defaultUserId,
      email: null,
      isAuthenticated: false,
    };
  }

  try {
    const v = await verifyJwt(token, settings);
    return { userId: v.userId, email: v.email, isAuthenticated: true };
  } catch (e) {
    if (e instanceof JWTValidationError) {
      throw new HttpError(401, "인증이 필요합니다.", { "WWW-Authenticate": "Bearer" });
    }
    throw e;
  }
}

/** 쓰기 엔드포인트 게이트 — 익명 데모 방문자 401. 모든 write 경로에 반드시 적용. */
export function requireAuthenticatedUser(user: CurrentUser): CurrentUser {
  if (!user.isAuthenticated) {
    throw new HttpError(401, "로그인이 필요합니다.", { "WWW-Authenticate": "Bearer" });
  }
  return user;
}

/**
 * app/routers/auth.py 의 _extract_request_token 포팅.
 * getCurrentUser 와 **동일한 우선순위**(Bearer → 쿠키)로 현 요청의 토큰을 돌려준다 —
 * /auth/me 가 Realtime 용으로 forward 하는 값이므로 검증에 쓴 토큰과 반드시 같아야 한다.
 */
export function requestToken(req: Request, settings: Settings): string | null {
  return bearerToken(req) ?? cookieToken(req, settings);
}

/** admin 게이트 — auth_enabled=false 면 통과, owner 미설정이면 전면 403. */
export function requireAdmin(user: CurrentUser, settings: Settings): CurrentUser {
  if (!settings.authEnabled) return user;
  if (!user.isAuthenticated || !settings.ownerUserId || user.userId !== settings.ownerUserId) {
    throw new HttpError(403, "운영자 권한이 필요합니다.");
  }
  return user;
}

/** app/main.py 의 CORSMiddleware 포팅. credentials=true 이므로 와일드카드 금지. */
const VERCEL_PREVIEW = /^https:\/\/.*\.vercel\.app$/;

export function corsHeaders(
  origin: string | null,
  allowed: string[],
): Record<string, string> {
  const base: Record<string, string> = {
    "Access-Control-Allow-Credentials": "true",
    "Access-Control-Allow-Methods": "GET, POST, OPTIONS",
    "Access-Control-Allow-Headers": "*",
    "Vary": "Origin",
  };
  if (!origin) return base;
  if (allowed.includes(origin) || VERCEL_PREVIEW.test(origin)) {
    base["Access-Control-Allow-Origin"] = origin;
  }
  return base;
}

/** preflight 응답. 핸들러 진입 전에 처리한다. */
export function preflight(req: Request, allowed: string[]): Response | null {
  if (req.method !== "OPTIONS") return null;
  return new Response(null, { status: 204, headers: corsHeaders(req.headers.get("Origin"), allowed) });
}

Edge Functions 는 기본값으로 **게이트웨이가 `Authorization` 헤더의 JWT 를 먼저 검증**한다. 그런데 브라우저 직접 호출은 `credentials: 'include'` 로 **쿠키만** 보내고 `Authorization` 헤더가 없다 — 게이트웨이에서 401 이 나 함수 코드에 도달조차 못 한다. 익명 데모 방문자도 마찬가지다.

인증은 `_shared/current_user.ts` 가 직접 수행하므로 게이트웨이 검증은 반드시 끈다.

`supabase/config.toml` 에 선언(배포 플래그를 매번 기억하지 않도록):

```toml
[functions.api-account]
verify_jwt = false
```

```bash
supabase functions deploy api-account --no-verify-jwt
curl -s "https://<PROJECT_REF>.supabase.co/functions/v1/api-account/auth/me"
```

> **이후 모든 함수(`api-search`/`api-answer`/`api-documents`/…)에 동일 설정이 필요하다.** 예외는 `billing-run`(shared secret 게이트)과 `email-webhook`(shared secret 게이트) — 이들도 자체 인증이므로 역시 `verify_jwt = false` 로 두고 secret 으로 막는다.

Expected: `{"authorized":true,"user_id":"<OWNER UUID>","email":null,"access_token":null}`

> `Authorization` 헤더가 아예 없는 요청이 **200 으로 돌아오는 것 자체**가 `verify_jwt = false` 가 먹었다는 증거다. 401 이 오면 게이트웨이가 아직 막고 있는 것이므로 Step 4 설정을 다시 확인한다.

## Task 1.7: Cloudflare 리버스 프록시 — 도메인·경로 보존

**Files:**

- [ ] **Step 1: wrangler.toml 작성**

```toml
name = "jetrag-api-proxy"
main = "src/index.js"
compatibility_date = "2026-08-01"
workers_dev = false

[vars]
SUPABASE_FUNCTIONS_BASE = "https://<PROJECT_REF>.supabase.co/functions/v1"
# 미이관 경로를 넘길 기존 백엔드. Phase 6 에서 빈 문자열로 바꾸면 Railway 의존 종료.

[[routes]]

```

- [ ] **Step 2: 프록시 구현 — 경로별 점진 전환 지원**

```js
/**
 * jetrag-api.woong-s.com → Supabase Edge Functions 리버스 프록시.
 *
 * 두 가지를 동시에 푼다:
 *  1) 쿠키 도메인 — 브라우저가 .woong-s.com 쿠키를 계속 보낼 수 있게 도메인을 유지.
 *  2) 경로 구조 — /search 를 /functions/v1/api-search 로 매핑해 프론트 변경 0.
 *
 * ROUTES 에 없는 경로는 LEGACY_ORIGIN 으로 넘긴다 — Phase 별로 한 줄씩 옮기며
 * 점진 전환하고, 전부 이관되면 LEGACY_ORIGIN 을 비워 Railway 를 끊는다.
 */
const ROUTES = [
  [/^\/auth\//, "api-account"],
  [/^\/health$/, "api-account"],
  // Phase 2 에서 해제: [/^\/search/, "api-search"], [/^\/answer/, "api-answer"],
  // Phase 3 에서 해제: [/^\/documents/, "api-documents"],
  // Phase 4 에서 해제: [/^\/payments/, "api-payments"], [/^\/billing/, "billing-run"],
  // Phase 5 에서 해제: [/^\/email/, "email-webhook"],
];

export default {
  async fetch(request, env) {
    const url = new URL(request.url);
    const match = ROUTES.find(([re]) => re.test(url.pathname));

    if (!match) {
      if (!env.LEGACY_ORIGIN) {
        return new Response(JSON.stringify({ detail: "Not Found" }), {
          status: 404, headers: { "content-type": "application/json" },
        });
      }
      const legacy = new URL(url.pathname + url.search, env.LEGACY_ORIGIN);
      return fetch(new Request(legacy, request));
    }

    const target = new URL(`${env.SUPABASE_FUNCTIONS_BASE}/${match[1]}${url.pathname}${url.search}`);
    const proxied = new Request(target, request);
    // 원본 경로 보존 — Edge Function 이 라우팅에 사용한다.
    proxied.headers.set("X-Forwarded-Path", url.pathname);
    return fetch(proxied);
  },
};
```
